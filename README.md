# مواقيت 🌙

تطبيق مواقيت الصلاة يعمل على الجوال (آيفون وأندرويد) ويُثبَّت من المتصفح مباشرة، بدون متجر تطبيقات.

## المزايا
- مواقيت الصلاة حسب موقعك تلقائيًا (GPS) أو باختيار المدينة
- طريقة **أم القرى** المعتمدة في السعودية افتراضيًا (الفجر عند زاوية ١٨٫٥ درجة، والعشاء بعد المغرب بـ ٩٠ دقيقة و١٢٠ دقيقة في رمضان)
- العد التنازلي للصلاة القادمة
- التاريخ الهجري حسب تقويم أم القرى
- جدول ٣٠ يومًا
- اتجاه القبلة مع بوصلة
- طرق حساب أخرى، ومذهب العصر، وتعديل يدوي بالدقائق
- يعمل بدون إنترنت بعد أول فتح

## التثبيت على الجوال
افتح رابط التطبيق:

**https://saleh12zx.github.io/mawaqeetv2/**

- **أندرويد (Chrome):** اضغط زر «تثبيت» داخل التطبيق، أو قائمة ⋮ ← «تثبيت التطبيق».
- **آيفون (Safari):** زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

## تشغيل GitHub Pages (مرة واحدة)
Settings ← Pages ← Source: **Deploy from a branch** ← Branch: **main** و **/(root)** ← Save.

## تحديث التطبيق
بعد أي تعديل على الملفات، غيّر رقم `VERSION` في ملف `sw.js` حتى يحدّث الجوال نسخته المحفوظة.
